# ADR 0004：竞赛价值评分模型

- 状态：已采纳
- 日期：2026-11-01

## 背景

需要可解释、可复现的竞赛比较，但不能伪造官方排名或把未知数据当作确定分数。评分必须允许社区讨论与版本化调整。

## 决策

采用六维加权模型（版本 1.0.0）：

- 技术深度 25%
- 行业/学术认可度 20%
- 实践与创新价值 20%
- 竞争难度 15%
- 学习成长收益 15%
- 参与成本可承受性 5%

规则：

1. 权重之和必须为 1；维度分 0–100。
2. 未知维度不记为 0/100；部分维度只产生“暂定分”，显示覆盖率，不排名。
3. 正式排名要求数据 verified、评分 approved、置信度 ≥ medium、六维齐全、核验在 18 个月内。
4. 同分共享名次，下一名次跳过。
5. 模型版本化，变更记录在 `changelog`。
6. 页面展示维度分、理由、证据等级、模型版本、覆盖率与免责声明。

## 备选方案

- **单一总分**：不可解释，容易误导。
- **按已知维度重归一化后仍排正式榜**：会让缺失数据的条目获得虚假确定性，拒绝。
- **用户直接打分**：需要账户、限频与反刷，首版没有后端，拒绝。
- **机器学习排序**：没有可靠训练数据，且不可解释，拒绝。

## 后果

- 评分是编辑初评，存在主观性；需要维护者/领域评审复核。
- 成本维度在缺少官方费用时使用保守估计，证据等级较低。
- 正式榜单可能条目较少；平台接受“宁缺毋滥”，不填充假数据。
- 未来调整权重需要新版本与重新评分。
