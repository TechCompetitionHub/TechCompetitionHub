# ADR 0002：单包仓库与领域目录

- 状态：已采纳
- 日期：2026-11-01

## 背景

PRD 推荐 `apps/web` + `packages/domain` 的逻辑结构，但也说明若单仓库工作区配置过度复杂，可先采用单一应用。首版只有一个站点，领域逻辑尚未被第二个应用复用。

## 决策

采用单一 npm 包（根目录即应用），领域逻辑放在 `src/lib/domain/`，数据访问放在 `src/services/`，数据与内容放在根目录 `data/`、`content/`。

不使用 npm workspaces、Turborepo 或 Nx。

## 后果

- 依赖安装、CI、Vite 配置与贡献流程更简单。
- 领域逻辑仍与 UI 解耦（纯函数、可测试），未来可以无痛拆到 `packages/domain`。
- 若未来出现第二个应用（如管理后台），需要重新评估工作区结构。
- 目录结构与 PRD 的“逻辑结构”一致，只是物理上合并为一个包。
